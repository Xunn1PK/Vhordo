# Vhordo: Chord Sheet Manager

![Vhordo: Chord Sheet Manager](./public/og-image.jpg)

> [Chordo](https://github.com/ChurchApps/Chordo) fork aimed to bring GitHub integration and more QoL features

> [!IMPORTANT]
> AI was used in this fork's development. I.e. this fork is vibecoded. I know that not everyone would be fine with AI generated code, so I thought that this is important information. However if you don't mind, there you go! 

### Features

- Import Text / ChordPro
- Import Images / PDFs
- Import any URL (auto parse chords/lyrics)
- Set a playback URL to YouTube/Spotify
- Create setlists
- Share with others
- Transpose
- Metronome
- Annotation
- Auto scroll
- Dark/light mode
- Pull data from ChurchApps (B1.church) and Planning Center
- And much more

### Fork changes
- Pull data from GitHub
- Search by not only song's name, but also lyrics and artist
