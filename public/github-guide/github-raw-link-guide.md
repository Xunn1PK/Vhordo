[!NOTE]
> For this method you must already have a GitHub repo with vhordo-database.json file or link to it. If you don't, then read [Standart mode guide](./public/github-guide/github-integration-guide.md)
>
> Also keep in mind that this method is read only, i.e. you couldn't upload your changes, only load database from GitHub repo

#### Step 1. Get raw link
1. Open repo with database (it could be your database or someone else's)
2. Open vhordo-database.json file
3. Click raw
4. Copy link

### Step 2. Configure Vhordo
1. Open Vhordo
2. Open settings
3. In GitHub section click connect
4. Click 'Use a raw link (read-only)'
5. Insert copied link from step 1 and click OK
